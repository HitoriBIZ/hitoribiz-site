「弦楽チューナー」は、バイオリン、ビオラ、チェロの開放弦調弦に特化したチューナーです。

対応する開放弦：
・バイオリン：G3 / D4 / A4 / E5

## English metadata

### Subtitle

Violin, Viola & Cello Tuning

### Keywords

tuner,violin,viola,cello,strings,pitch,tuning,orchestra,reference tone,open string

### Promotional text

Simple open-string tuning before practice or rehearsal, with violin, viola, cello, and A4 440–444 Hz support.

### Description

String Tuner is designed for open-string tuning on violin, viola, and cello.

Supported open strings:
• Violin: G3 / D4 / A4 / E5
• Viola: C3 / G3 / D4 / A4
• Cello: C2 / G2 / D3 / A3

Key features:
• Real-time pitch detection using the microphone
• Adjustable A4 reference: 440 / 441 / 442 / 443 / 444 Hz
• Reference tone for every supported open string
• Designed for iPhone and iPad
• Available in English and Japanese

Use it before individual practice, orchestra rehearsal, or ensemble preparation. Microphone detection stops while a reference tone is playing, preventing the app from measuring its own output.

Microphone audio is used only for on-device pitch analysis. Audio is never recorded, stored, transmitted, or uploaded.

## App Review notes

The app uses the microphone only for real-time, on-device pitch detection. No audio is recorded, stored, transmitted, or uploaded. Tap “Listen” and play the selected open string. Tap “Tone” to hear the reference pitch; microphone detection automatically stops during reference-tone playback.

The app does not require an account, does not contain advertising, and does not include in-app purchases.
